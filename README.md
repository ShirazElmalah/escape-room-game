משחק חדר בריחה בדפדפן. השחקן בוחר אווטאר, נכנס לחדרים
בנושאים וברמות קושי שונים, ופותר חידות כדי לברוח.

🚧 בפיתוח – שלב 0: הכנות

- Python (בהמשך, לצד השרת)

2. פותחים את `index.html` בדפדפן, או משתמשים בתוסף Live Server
